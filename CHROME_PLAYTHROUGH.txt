SWITCH GAMES — CHROME DEVTOOLS PLAY-THROUGH
Run date: 20 October 2026, America/Chicago (reports use UTC timestamps)

METHOD AND SCOPE

Installed Google Chrome 156.0.8078.48 on macOS, headless, controlled through
the Chrome DevTools Protocol. This was automated closed-loop play, not a
human manually operating the DevTools UI. The test player read live state
and sent trusted keyboard events. Gameplay used the real animation loop;
ordinary play did not award points, disable collisions or move game objects.

All 25 games were exercised in both switch modes, with ordinary level-1
starts and separate level-2/3 diagnostic starts: 150 initial configurations.
Ordinary runs requested 30 seconds; diagnostic runs requested 15 seconds.
Natural game-over ended a phase early. Further focused retests used longer
runs, and Tetris received 180 seconds of ordinary play in each mode.

Later-level fixtures explicitly seeded level-dependent state; they were NOT
earned progression. Physics/collision, scoring and line-clear probes also
seeded particular edge cases. Each report labels those phases. No claim is
made that the player won every game or earned every level.

SOUND

Sound effects and spoken names were disabled in an isolated profile before
the app loaded. Chrome additionally ran with --mute-audio. Gameplay samples
monitored both settings and AudioContext construction. No sound-policy
violation was observed. Live-region DOM cues were tested without enabling
speech, sound or a screen reader.

SETTINGS AND EVIDENCE

- Speed 5, practice off, step scanning. Hold-to-pause disabled for ordinary
  gameplay so continuous thrust/advance/flipper holds were possible.
- A separate probe enabled and verified hold-to-pause, including input clear.
- 1280x900 gameplay viewport. Additional 375x667 and 667x375 layouts, large
  text and Arabic RTL settings were checked through Chrome and screenshots.
- Return via Escape/Home preserved page and focus; P froze/resumed simulation.
  Touch press/release, step scanning and dialog Tab wrapping were exercised.
- Reports record browser version, app.js SHA-256, phases, simulation time,
  screenshots, scores, levels, inputs, runtime exceptions and network failures.
- A natural defeat was recorded as such. Where a game survived, the test set
  gameOver only AFTER play to exercise restart/pause/menu UI; this is explicitly
  labelled forcedEndForNavigationOnly, never counted as a natural defeat.
- A technical case pass means valid sampled state and working lifecycle UI,
  not that the game was won or its difficulty certified. Screenshot review
  found Pinball's runaway progression despite its initial technical pass.

BUGS FIXED AND RETESTED

1. Pinball: right flipper moved down when pressed. Both flippers now lift.
2. Pinball: holding the other switch powered an inactive flipper. Bounce power
   now comes only from the flipper actually contacted; rebounds aim inward.
3. Breakout: a ball already below the paddle could be saved from underneath.
   A downward crossing of the paddle's top face is now required.
4. Snake: entering the tail cell on the move that vacated it caused a loss.
   Collision checks now exclude that cell unless the snake is growing.
5. Simon: displayed level lagged the current sequence. It now updates when
   the next sequence is created.
6. Pong: missed balls could be returned from behind the paddles. Collision
   now requires an approaching ball crossing the paddle face, once.
7. Bubble Shooter: attachment could reuse occupied cells or extend a bubble
   past a side wall. It now chooses a free, connected, in-bounds hex cell.
8. Pong: later-level AI could match/exceed every possible vertical return.
   Tracking speed is now capped; Chrome verified level-3 shots can score.
9. Space Dodge: Math.floor(sm) awarded no survival points at slower speeds.
   Fractional progress is retained. Speed-1 scoring now works in both modes.
10. Repeated target cues: a second mole on the same side was not announced
    after an empty interval. Expired cues now clear, allowing a fresh cue.
11. Penalty Kick: later-level tracking made even a best-placed shot unscorable.
    Goalkeeper reaction is now bounded. A level-10 shot scored in both modes.
12. Pinball: score thresholds caused repeated level-ups, and unlimited random
    overlapping bumpers eventually filled the table. Each level now requires
    fresh points; bumpers are limited and placed without overlap.

Each fix has an automated regression test; targeted Chrome probes and game
retests accompany the source changes. The static app bundle and offline-cache
version were rebuilt. The local Node suite passes 51 tests.

LIMITATIONS / RELEASE FOLLOW-UP

- Automated play has imperfect timing and strategy. Early losses are not
  automatically game bugs; seeded levels are not evidence of earned wins.
- One-switch Tetris survived the longer run but did not clear a line; the
  two-switch player did. Diagnostic four-line clears verified scoring and
  level transition in both modes. Human one-switch playability remains a
  particularly useful acceptance test.
- Many faster games reached later levels naturally; other games were tested
  at later levels only with diagnostic fixtures. See the coverage matrix below.
- This is not physical switch-adapter/gamepad testing, iOS Safari testing,
  Android-device testing, screen-reader listening or native-speaker review.
- Service workers were bypassed to avoid stale test builds. Offline/install
  and upgrade lifecycle testing is separate from this gameplay run.
- Comfort, fatigue, suitable pacing and independent play need testing with
  intended one-/two-switch users. No automated pass substitutes for that.

FINAL VERIFICATION RESULT

Both final-verified reports completed: 25/25 game cases and all included probes
passed in each mode. Both used the final bundle hash above. No uncaught
JavaScript exceptions or failed network loads were recorded in those runs.
The separate scoring-retest reports also completed with all checks passing.

Across full, retest, cue-after, fixture-retest, scoring-retest, endurance and
final-verified: 272 gameplay phases, 67,359 sampled states, 76.4 aggregate wall
minutes of play (76.0 simulated minutes). These totals include ordinary play,
diagnostic fixtures and repeated checks; workers ran in parallel, so they are
NOT elapsed user waiting time. Pilots and failed before-fix probes are excluded.
No sound-policy violations or uncaught game exceptions were observed.

Screenshots of all 25 games in both modes were visually reviewed, along with
responsive/RTL screens and the repaired later-level Pinball layout. Temporary
Chrome instances and local servers were closed; test evidence is retained.
